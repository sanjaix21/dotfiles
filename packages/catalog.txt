#   on            checked by default when not installed yet

#   needs=a,b/c   packages it is useless without; b/c means either one (checked at the summary)
#   role=a,b      job it does; two picks with the same role get a "redundant" warning
#   svc=unit      systemd system unit to enable
#   usvc=unit     systemd user unit to enable
#   hook=file     script in hooks/ to run after install
# Notes must not contain "|" or ",".
